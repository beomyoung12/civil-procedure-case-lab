# 민사소송법 · 사례와 공통법리

## 켜기

`start-local.cmd`를 더블클릭하면 내부 주소 http://127.0.0.1:4192/ 를 엽니다.
이미 켜져 있으면 주소만 열면 됩니다. 종료는 실행창에서 Ctrl+C입니다.
Python 없이 `index.html`을 직접 열어도 작동합니다. 주소·브라우저가 달라지면 저장기록은 별개입니다.

## 두 화면

1. **반복 법리 모아보기**: 43개 모두에 ‘어떤 상황에서 쟁점인가 → 일반적 판단 기준 → 요건·판단 순서 → 예외·혼동 주의’를 보충했습니다. 조문·확인한 판례 링크, 관련 문제와 원문을 연결합니다. 갑·을·병에 관한 사안의 결론은 일반 법리와 구별하여 문맥 안에서 읽습니다. 검색은 보충한 법리와 조문 번호도 찾습니다.
2. **단원별 문제**: 18개 단원, 107개 기존 사례분류. 동일·유사 설문이 통합된 학습용 분류 수이며, 실제 원문 설문 수나 실제 출제 횟수는 아닙니다. 정리자료 기반 보충 8개는 기본 목록에서 제외하고 체크하면 표시합니다.

문제를 열면 왼쪽 문제 요지 / 오른쪽 내 답안입니다. `모범답안 보기`를 누르면 오른쪽만 원문으로 바뀝니다. 내 답안으로 돌아오면 작성 내용이 보존됩니다. 모바일은 문제 / 답안 탭으로 전환합니다.

작성 내용은 매 입력 때 자동 저장됩니다. 새로고침·문제 이동 후에도 이어서 쓸 수 있습니다. 저장·내보내기에서 답안과 공부표시를 파일로 보관하고 복원할 수 있습니다. 공부표시는 사용자가 직접 한 표시이며 암기완료나 법적 정확성 판정이 아닙니다. 자동채점은 이 새 화면에 없습니다.

## 원문과 학습용 안내의 구별

- 왼쪽의 기본 문제 요지는 기존 학습용 요약입니다. 정확한 문제 문장은 `원문 문제 보기`로 확인하세요.
- **기본 본문은 `원자료_TXT/02_단원별`의 교정 TXT입니다.** 18개 단원의 107개 사례와 자료 수록 답안 101개를 연결했습니다. 답안이 없는 6개 사례는 미수록으로 표시하며 생성 답안으로 대체하지 않습니다. 스캔 자료도 이번에 교정한 TXT를 기본으로 표시합니다.
- 교정에는 갑·을·병 한글 표기와 분명한 오인식·줄바꿈 정리가 포함됩니다. 이번 작업에서 이미지나 OCR을 다시 읽지 않았으므로 **이미지 대조 확정 전사본은 아닙니다.** 확정하기 어려운 날짜·금액·소실된 문장과 기존 법적 결론은 임의로 바꾸지 않았습니다.
- 선택한 답안의 TXT 연결 구간 전체를 읽습니다. 페이지가 넘어간다는 이유로 문장을 잘라 표시하지 않습니다. 첫 관할합의 사례의 ‘반면 물권적 승계인…’과 결론도 이어집니다. 본문 17px·줄간격 1.95와 목차 구분을 유지했습니다.
- 설문 경계가 미지정된 사례는 TXT에 담긴 공통 사실관계·인접 설문이 함께 표시되며 안내를 붙였습니다. 여러 출제 변형이 통합된 경우 선택한 TXT의 범위를 표시합니다.
- **원본·쪽별 대조**를 누르면 PDF 이미지·직접 추출문 뷰어로 전환합니다. **교정 TXT로 돌아가기**로 복귀합니다. 원본 PDF·이미지·옛 직접 추출문과 검수 좌표는 보존했습니다. 옛 추출문을 보는 모드에는 교정 전 자료임을 표시합니다.
- 원본 대조 화면의 **페이지 전체 보기 / 원문 확대 / 전체 PDF** 기능은 유지됩니다. 이미지의 노란 띠는 위치 안내용이며 정밀한 글자 윤곽 표시가 아닙니다.
- 반복법리 화면의 자료 발췌도 교정 TXT에서 실제 확인되는 문구로 갱신했습니다. 일반 법리 정리와 구별하며, **본문 대조**를 누르면 교정된 사례 답안을 펼쳐 해당 문단을 표시합니다. 원래 검수 발췌 데이터는 보존합니다.
- 질문만 있는 자료에 생성 답안을 모범답안으로 표시하지 않습니다. 2023년 대위소송 문항은 과거 다른 출제문제의 대조답안을 연결하고 명확히 구별합니다.
- 판례변경과 법적 결론의 교정은 별도로 표시합니다. 명백한 오타·조문 표기 교정과 법리의 변경을 혼동하지 않도록 구별합니다. 추심명령의 2025년 전원합의체 변경, 사망 시점·소송대리인, 국제적 소송경합, 문서 진정성립 등 보충에 필요한 공식 근거를 대조했습니다. 모든 현행 법령·판례를 망라한 검증은 아닙니다.
- 빈출의 기준은 이 자료에서 연결되는 사례분류 수입니다. 전국 통계나 실출제 횟수로 오인하지 않도록 표시했습니다.

## 파일 구성 / GitHub

새 화면의 실행 파일:

```
index.html
reading.css
reading.js
reading-core.js
reading-focus-core.js
reading-readable-core.js
reading-transcript-core.js
data.js
reading-data.js
reading-source-text.js
reading-focus.js
reading-edits.js
reading-transcripts.js
source-pages/        # 원문 페이지 이미지
sources/            # 원문 PDF, 정리자료 읽기용 HTML
```

`serve.py`, `start-local.cmd`는 내부 실행용이라 GitHub Pages에서는 필요 없습니다. `content/`, `tools/`, `work/`, `tests/`는 내용 유지보수·검증용이며 사이트 실행에는 필요 없습니다.

기존 `민사논증-깃헙업로드용` 폴더와 ZIP은 **이전 버전**입니다. 새 화면을 올리려면 위 새 실행 파일을 사용해야 합니다.

교수님 문제·모범답안·정리자료 PDF, 이미지, 발췌 및 내장 텍스트를 포함합니다. **공개 업로드 허락 없이 공개 GitHub 저장소나 공개 Pages에 올리지 마세요.** 이 자료 범위가 들어간 완전한 사이트는 현재 개인용 내부 실행 기준으로 구성했습니다. 단순히 PDF만 제외해도 이미지·텍스트에 원문이 남습니다.

기존 화면을 계속 쓰려면 `legacy.html`, `styles.css`, `app.js`, `grading.js`도 함께 보관하세요. 이전 브라우저 저장키는 변경하거나 초기화하지 않았습니다.

## 유지보수

현재 기본 본문: `원자료_TXT/02_단원별/*.txt`
교정 TXT 웹 데이터 생성: `tools/build-website-transcripts.mjs` (기존 교정 기록의 파일 해시와 일치해야 실행)
발췌 구간 보정: `content/website-quote-selections.json` (현재 TXT의 명시적인 시작·끝 문구)
생성 결과: `reading-transcripts.js`, `work/website-transcript-report.json`
표시·자료 선택: `reading-transcript-core.js`
TXT 자체와 아래 옛 원본 대조용 데이터는 별도로 보존합니다. 원본 대조 빌더만 다시 실행해도 교정 TXT가 덮어써지지 않습니다.

반복 법리 연결: `content/law-groups.json`
일반 법리 보충: `content/law-guides.json` (원문과 별도)
문제·답안 선택 구간: `content/source-focus.json` (정확한 텍스트 경계 또는 검토한 이미지 좌표)
원문 표시 데이터 생성: `tools/build-reading.py`
구간·형광표시 생성: `tools/build-source-focus.py` (앞 빌더 이후 실행)
읽기용 교정 내역: `content/source-edits.json` (PDF·쪽·정확한 원문 위치·교정 근거)
교정 데이터 생성: `tools/build-readable.mjs` (위 빌더들 이후 실행)
문단·목차·띄어쓰기 표시: `reading-readable-core.js` (원본 데이터와 분리)
원문 PDF·직접 추출 텍스트 및 검수 인용: 기존 `data.js`, `work/extracted/`, `sources/`
원문 페이지 이미지: `source-pages/`

빌더는 원본 PDF SHA-256을 대조하고 모든 관련 페이지 범위를 검사합니다. 텍스트는 직접 PDF 추출만 사용하고 선택된 문자열의 SHA-256도 저장합니다. 원본 매핑을 덮어쓰지 않고 누락된 다음 페이지를 보충합니다. 생성 결과는 `work/reading-build-report.json`, `work/focus-build-report.json`에 저장합니다. Node 자동 검사는 `node --test tests/*.test.mjs`로 실행합니다.
